# Lab 01: CIA Triad & Security Fundamentals Challenge

> **Course Alignment:** Chapter 1 — Introduction to Ethical Hacking and Security Fundamentals

---

## Objectives
This hands-on challenge evaluates practical understanding of the core **CIA Triad** pillars:
- **Integrity:** Validating cryptographic hashes (SHA-256) to verify data authenticity and detect tampering.
- **Confidentiality:** Decoding obfuscated data (Base64) and extracting password-protected archives.
- **Availability:** Successfully restoring access to authorized payloads.

---

## Challenge Artifacts
This directory contains the following assets:
- `target_a.rar`
- `target_b.rar`
- `checksum.txt`
- `key.txt`

---

## Student Mission
1. Analyze the two archive files (`target_a.rar` and `target_b.rar`).
2. Use cryptographic hash verification to identify which package is authentic and uncompromised.
3. Retrieve and decode the authentication secret required to open the valid package.
4. Extract the secret payload to verify your solution.

---

*Good luck, and remember: verify before you trust!*
